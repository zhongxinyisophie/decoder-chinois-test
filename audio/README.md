# 前四课真人词句音频

用户于2026-10-02提供四课原始录音。此目录包含按录音稿顺序切分的80个片段（L1/L2/L3/L4：15/15/24/26）。课程文件 audio 字段按准确中文文本指向片段路径；词、句及排序播放复用现有 Decoder.say。

manifest.json 中 sourceStart/sourceEnd 为各课原始M4A中的秒数；sha256校验切分文件。完整原始录音和本地语音识别模型不提交仓库。整段听力继续使用现有YouTube链接。

后续重新录制应保持对应中文与课程原文一致。若替换片段，请同步其哈希和来源边界（来源变化时重新记录），并重新验证播放。真实设备兼容性及教师逐条听审参见 docs/project-status.md。
